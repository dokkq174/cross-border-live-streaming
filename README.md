## 卡顿的四个原因：三个都指向网络

直播间弹幕开始刷“卡了”，画面一帧一帧地跳，观众等不到下一秒就退出去。多数人第一反应是设备不行，换手机、换显卡，换完发现照旧。

**上行带宽不够。** 家用宽带的典型特征是下行快、上行慢，100M 的家宽下行能跑满，上行往往只有 10Mbps 甚至更少。直播吃的是上传，不是下载。下行 100M 看着漂亮，上行 5M 一开播就不行。

**延迟和丢包。** TikTok 官方建议 RTT 控制在 200ms 以内，理想值 150ms 以内；丢包率官方能容忍 2% 以下，但实际体验要做到顺畅，最好压到 0.5% 以内。普通中转线路跳数多，抖动一上来就开始跳帧。

**IP 不干净。** 这是 TikTok 独有的麻烦。平台对账号所在 IP 的原生度很敏感，机房 IP、共享 IP、被反复使用过的 IP，容易触发限流甚至 0 播放。带宽再大，IP 不行，推流照样推不动。

**设备过载。** 这一项最次要也最好解决。CPU 持续 90% 以上、OBS 提示“编码过载”，本质是编码跟不上，降分辨率或换 H.265 就能缓解。

前三条都指向同一件事：网络。所以排查顺序应该是先测上行和丢包，再看 IP 属性，最后才考虑硬件。

## 带宽到底要多少：官方下限和实战值差了好几倍

TikTok Live Studio 官方文档写的最低上传带宽是 2.5Mbps 以上。这个数字的意义是“能跑起来”，不是“能播好”。真按 2.5M 推 1080P，画面会直接变成马赛克。

行业里通用的实战参考值是这样的：

| 直播方式 | 最低带宽 | 推荐带宽 | 典型场景 |
| --- | --- | --- | --- |
| 手机直播（720P） | 5Mbps | 5–10Mbps | 单人出镜、轻度带货 |
| OBS 推流（1080P/30fps） | 10Mbps | 10–20Mbps | 电脑直播、电商带货 |
| OBS 推流（1080P/60fps） | 15Mbps | 20Mbps 以上 | 高清游戏、才艺直播 |
| 多账号矩阵直播 | 按账号数叠加 | 每账号独立带宽 | 矩阵带货、无人直播 |

推荐值要留一倍以上余量的原因很简单：码率不是匀速消耗的，高峰瞬间可能冲到平均值的 1.5–2 倍。没有缓冲，峰值一来就丢包，丢包就卡。

另一套更粗但也更实用的规划法是按设备数算：每 5M 带宽对应约 1 台直播设备，10M 约 2 台，20M 约 4 台，50M 约 10 台。这个口径的好处是不用纠结单台设备到底要 8M 还是 12M，直接按“同时开几台”下单。

手机和电脑的要求为什么不同？手机通过 TikTok App 直播时，平台和系统会根据网络状况做一定程度的画质和码率自适应，推流链路短；电脑走 LIVE Studio 或 OBS，分辨率、帧率、码率、编码器全部手动可控，1080P 30fps 的实际码率通常在 4000–6000 Kbps，加上音频和协议开销，10M 才是安全的起点。

这里有个容易被忽略的细节：5M 要理解成“直播业务能稳定使用的带宽”，不是测速偶尔跑到 5Mbps 就万事大吉。测速是瞬时峰值，直播是持续占用。

流量消耗方面，按 1080P/30fps 推流 4000–6000 Kbps 算，一小时上行流量大约 1.8–2.7GB。一天播 4 小时、一个月播 25 天，光推流就是 180–270GB，再加上回看、互动、养号、素材上传，一个月 300GB 以上是常态，重度带货团队 1TB 也不夸张。

## VPN 和共享 VPS 为什么救不了直播

“挂个梯子不就行了”是很多人的第一反应，试过的都知道不行。

普通 VPN 走公共中转节点，节点拥挤时延迟和丢包完全不可控，高峰期延迟飙到 300ms 以上很正常。更致命的是 IP——VPN 的出口 IP 几乎都是机房 IP，而且是被无数人反复用过的“脏 IP”，平台一识别就限流。

共享 VPS 看起来便宜，但带宽是几十人共抢的，你开播的时候隔壁在跑爬虫，画面照样卡。IP 同样是机房段，原生度差。

还有一层是合规。出境通道分两类：一类是运营商国际专线（IEPL、MPLS 等），具备资质的服务商提供、企业实名签约、线路质量有保障；另一类是个人或小作坊搭建的代理通道，线路不稳定，也存在合规风险。做长期生意，第一类才是能签合同、能开发票、出事有人负责的选择。

## 开播前的自检清单

网络到位之后，这几项决定你能否把带宽真正用起来：

1. **OBS 以管理员身份运行**，否则 Windows 的资源调度优先级不够，编码容易卡顿
2. **编码器优先 NVENC（N 卡）或 AMF（A 卡）**，软编 x264 对 CPU 压力大，1 核 2 核的机器尤其扛不住
3. **1080P/30fps 推 4000–6000 Kbps 就够**，超过 8000 Kbps 收益递减还容易丢包
4. **关键帧间隔设 2 秒**，这是 TikTok 官方推荐值
5. **音频采样率 48kHz、码率 128–160 Kbps**，别用 44.1kHz，会音画不同步
6. **开启“网络绑定优化”和“动态码率”**，网络波动时自动降码率保流畅
7. **开播前测一次上行和丢包**，上行低于目标码率 2 倍就别开

## 常见问题

**5M 到底够不够直播？**
单台手机做 720P 普通出镜、带货、聊天，5M 稳定带宽可以起步。但 5M 是“够用”，不是“适合所有场景”。一旦涉及高清、多人连麦、画面变化剧烈，或者还有别的设备共享网络，余量立刻见底。长期稳定做的，直接上 10M。

**为什么手机 5M 可以，电脑要 10M？**
手机走 App 推流，链路短、平台会做自适应；电脑走 LIVE Studio 或 OBS，分辨率帧率码率全手动，1080P/30fps 实际码率 4000–6000 Kbps，加上音频和协议开销，10M 才是安全起点。

**一个 IP 能登几个直播账号？**
建议一个 IP 对应一个账号。同一 IP 下登录多个账号容易触发风控，轻则限流重则封禁。矩阵运营的正确做法是准备多个独立 IP，而不是在一台机器上反复切换。

**这类方案合规吗？**
合规与否取决于通道性质。运营商国际专线（IEPL/MPLS）由持资质服务商提供、企业实名签约，用于跨境电商等合法经营；个人私自搭建或使用未经许可的跨境通道存在合规风险。买之前问清楚对方是不是持证经营、能不能签合同。

**多久能开通？**
LisaHost 是自动开通、即时交付，付款后几分钟内就能拿到 IP 和登录信息，进控制台可以重装系统。不满意 48 小时内无条件退款。

跨境直播网络这件事，没有“一买就灵”的答案。先量自己的上行，再数同时开播的设备数，然后决定是花钱买带宽的确定性，还是花钱买 IP 的干净度。把这两件事分清楚，套餐表上的数字才有意义。
